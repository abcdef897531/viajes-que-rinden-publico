Firma de producción para instalaciones nuevas. NO reemplazar el piloto del dueño con esta firma diferente; no desinstalar una versión con tus ajustes para resolver esa diferencia. La transición requiere respaldo y revisión acompañada.

La app ayuda a analizar ofertas visibles; vos decidís qué viajes aceptar. No acepta ni negocia viajes. La aceptación física de esta identidad de producción y el inicio de sesión real siguen pendientes. Cuentas centrales, ADMIN, transferencia del dueño y recepción automatizada de soporte todavía están pendientes de habilitación y comprobación. No se afirma funcionamiento certificado mundial, en tablets o en todos los diseños de oferta.

Este repositorio contiene instalador, guías y datos abiertos con sus avisos; excluye proyecto, claves y datos privados. El APK es inspeccionable y su ofuscación no garantiza secreto absoluto.

## Cambios de esta versión

Los correos de recuperación usan el idioma elegido en la app (español, inglés o portugués). Los avisos distinguen problemas de conexión, configuración e intentos excesivos sin revelar si una cuenta existe.
