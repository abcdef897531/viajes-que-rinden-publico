# Instalación y actualizaciones — 0.6.135

Un APK es el archivo instalador de Android. El [instalador de producción universal](updates/apks/ViajesQueRinden-0.6.135-universal.apk) se distribuye en este repositorio oficial. No se necesita tarjeta ni un período de prueba de pago para este flujo previsto.

Android puede pedir permiso para instalar desde el navegador o desde nuestra app. Confirmalo personalmente solo después de comprobar el origen. La app pide confirmación del sistema: no instala silenciosamente.

Una actualización debe conservar el nombre de paquete y una firma compatible. Antes de ofrecerla, la app comprueba destino, tamaño, huella, versión y firma. Si falla, se cancela el archivo para permitir un reintento.

La versión piloto del dueño y la futura producción tienen firmas diferentes. No uses la entrega de producción para reemplazar el piloto sin un procedimiento de transición y respaldo acompañado. No desinstales una versión que contiene tus ajustes para resolver un error de instalación.

La verificación de descarga remota se realizará después de subir esta entrega. La aceptación física de producción y el inicio de sesión real aún están pendientes. Publicar el instalador no habilita por sí solo soporte remoto, cuentas centrales ni ADMIN.
